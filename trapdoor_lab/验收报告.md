## 五·补五　二维弹塑性 FEM 力学场（本轮）

按用户 2026-11-24 授权（专著理论不足时可深入扩展与横向引用），横向引入成熟
有限元方法，交付第二层能力：真正的二维应力/塑性区数值场。

- 新增 `fem2d.py`：平面应变 Q4 等参单元（2×2 高斯积分）、Drucker–Prager 屈服
  `f=q+m·p−k`、径向返回映射（二分求根 + Rankine 拉力截断）、位移控制活门、
  修正 Newton（步初参考重算 + 松弛 0.4）、强度折减框架。
- **修复的四处数值缺陷（按发现顺序）**：
  1. 原 Newton 混合求根反复重置初值，大应变下卡死；改纯二分；
  2. 剪应力流动法向误写 `3·txy/q`（正应力为 `1.5·s/q`），破坏径向返回；改 `1.5·txy/q`；
  3. DP 锥对静水拉应力无上界，`m·p>k` 时塑性乘子无解、应力爆炸到 1e10；
     加 Rankine 拉力截断（土不抗拉），并修正平面应变 `szz=lam·(exx+eyy)`；
  4. `dp_yield` 返回 numpy 标量污染 JSON；源头转 Python `float`。
- **实跑结果**（l=2.5 m、h=3.0 m、γ=18 kN/m³、12×9 网格、12 步）：
  初始静止压力 58.5 kPa → 下沉后残余约 4 kPa（土拱形成，降幅约 93%）；
  塑性区占比 48.1%，集中在活门上方土柱并向上贯通；偏应力场 12–140 kPa；
  收敛标志为真，DP 本构自检全通过。三面板云图样本 `verify/fem_preview.png`
  目视确认应力拱、应力集中、塑性柱与压力—位移曲线形态正确。
- Web 新增 `/api/fem` 与「FEM 二维力学场」按钮；14 项回归测试
  `tests/test_fem2d.py` 覆盖本构自检、径向返回、拉力截断、弹性小应变、
  网格、曲线土拱趋势、塑性区增长、场量有界、对称性、强度折减与边界声明。
- 全量回归 82/82，自检 13/13，编译通过，JS `node --check` 通过。

**FEM 能力边界（不得混淆）**：这是横向引用的成熟有限元扩展，不是专著原有理论；

## 五·补七　FELA 极限分析上下界夹逼（本轮，方案 M7）

对照实施方案阶段三 M7：用一对对偶线性规划给出严格数学夹逼，补上 FEM
「非严格上下界」的缺口，并与专著 L1 闭式解直接对照。

**理论对应（专著 §7.3 / §7.7 / §20.4.2）**：上限取 Davis 折减后关联机构、下限取
不依赖 ψ 的静力场，二者夹逼真值。本模块把这套对偶落到线性化屈服面：
- `linearize_strength()`：幂型包线 τ(σ) 在应力区间取 K 段内接/外接线性夹持；
- 内接多面体→静力下限抗力 `Ra_LB`，外接→运动上限抗力 `Ra_UB`；
- 主动支护压力 `q=over−Ra/l` 是 Ra 的减函数，夹逼方向反转：`q∈[q_LB, q_UB]`；
- `davis_reduce()`：标准 Davis 折减 `tanφ_red=sinφ·cosψ/(1−sinφ·sinψ)`，
  对幂型按割线剪阻比等效折减 A；ψ>φ₀ 钳制为关联（ratio=1），ratio 随 ψ 单调增至 1。

**实跑核验**（l=2.5 m、h=3.0 m、K=12、41 点）：
- `Ra_LB=87.761 ≤ Ra_exact=87.835 ≤ Ra_UB=87.865` kPa·m，L1 精确解居中；
- 主动支护压力夹逼 `[18.854, 18.896]` kPa，L1 闭式 18.866 kPa 落在区间内；
- K=2→32 时夹逼带宽度 0.66→0.003 kPa 单调收窄（对数下降）；
- 下限与 ψ 严格无关（delta=0），Davis ratio 随 ψ 单调、折减上限单调下降；
- 深埋 h/D>1.4 标记 `out-of-range`、不给夹逼（幂型包线无临界状态封顶，避免伪造饱和数）。

**关键认知修正（如实记录）**：曾试图用 FELA 外推深埋稳定数并夹逼 N_sat=18.2212，
但专著幂型强度随 σ 单调增、Ra∝h^(1+B) 快于自重 γh，导致 q_a 变负发散——这是
模型口径错误而非真实现象。按 L3 的 `rate-degraded` 先例改为适用域门控：深埋不夹逼，
N_sat 仅作文献锚点对照。另 Davis 折减初用 `cosψ·cosφ/(1−sinφsinψ)` 非单调，
改用标准 tan 折减并加 ψ≤φ₀ 域检查后单调性成立。

- 新增 13 项 `tests/test_fela.py`（线性化内外接、夹逼性质、K 收窄、L1 落区间、
  ψ 无关下限、Davis 单调与钳制、适用域门控、JSON 可序列化、边界声明）。
- Web 新增 `/api/fela` 与「FELA 极限分析上下界夹逼」按钮，双面板夹逼带图
  （左：q 上下界随 K 收窄 + L1 参考线；右：区间宽度对数下降）。
- 四闸：104/104 回归、13/13 自检、py_compile（含 `fela.py`）、JS `node --check` 全过。

**边界**：线性化多面体极限分析，**不是 SOCP 圆锥规划**、不是幂型精确解；
下限与 ψ 无关，Davis 折减单独报告（不混入数学夹逼）；深埋不夹逼；
N_sat 不由此推导。完整 SOCP 仍未实现。

## 五·补八　DEM 颗粒流与三维锥形极限平衡（本轮，方案 M8）

对照实施方案阶段三 M8「DEM 独立后端 + 三维锥形」，在 aarch64 银河麒麟上完成
零新依赖的 M8 交付：

**1. 二维 DEM 离散元内核（`dem2d.py`）**
- Cundall–Strack 线性弹簧-阻尼接触 + 切向位移历史 + Coulomb 摩擦截断；
  速度 Verlet 显式积分；全对向量化接触搜索（N≤1200）。
- 活门关闭预沉积 → 开闸流动两阶段；逃逸颗粒（y<−2r）自由落体离场，
  避免底壁弹簧把穿透颗粒弹回导致动能爆炸。
- 实跑（360 颗粒、150+500 步、5.5 s）：活门反力 1283 N → 开闸 0，
  地表由 0.22 m 降至 0.06–0.12 m，峰值重叠 0.71R，`stable=True`。
  四阶段速度着色图 `verify/dem_preview.png` 目视确认漏斗成形与两侧向中心流动。
- **与运动学动画本质不同**：逐颗粒积分牛顿方程、有接触力与反力，非构造位移模板。

**2. DEM 独立进程适配器（`dem_backend.py`）**
- dem/v1 JSON 协议（stdin/stdout 或文件）；`local` 参考后端 + `ExternalDEMBackend`
  契约基类；CLI 双模式（`--input/--output` 与管道）。
- 严守方案许可证边界：Yade(GPL)/PFC(商业) 仅独立进程通信，不链接、不分发；
  本程序包只含自实现 MIT 参考后端，外部脚本由使用者自备。

**3. 三维锥形极限平衡（`cone3d.py`）**
- 轴对称漏斗/瓮形/井筒三形态滑体；W=γ∫πr²dz，
  S=∫(c+Kγ(h−z)tanφ)·2πr·√(1+(dr/dz)²)dz，q=(W−S)/(πr0²)；临界埋深二分。
- 实跑（l=2.5、h=3）：q=27.80/23.07/11.87 kPa，瓮形侧阻动员 82% 最高
  （滑面最宽），三形态剖面与量级对照图 `verify/cone_api.png` 正确。

**关键认知修正（如实记录）**：DEM 初版出现两类伪发散——① 诊断量 `overlap.max()`
误取含对角线的全矩阵（对角线 overlap=2r 是伪值），修为只对真实接触对取最大；
② 掉出模型的颗粒仍受底壁弹簧力，穿透越深力越大把颗粒弹飞（动能 1e5 J），
修为逃逸颗粒只受重力、不参与接触与边界力。两者均为数值实现缺陷，非物理模型问题。

**数值缺陷修正清单**：初始六角堆积半径扰动 ±10% 导致重叠 → 收紧到 ±4% + 间距裕度 1.08；
自检"不重叠"误算对角元素 → 加 off-diagonal 掩码；稳定判据 20%R 过严 →
改为全时段峰值 < 1R（无完全穿透）。

- 新增 24 项 `tests/test_dem_cone.py`；DEM 内核自检 10/10、适配器自检 9/9、
  锥形自检 12/12；Web 新增 `/api/dem`、`/api/dem_backend`、`/api/cone` 三接口与面板。
- 四闸：128/128 回归、13/13 自检、py_compile（含 3 个新模块）、JS `node --check` 全过。

**边界**：DEM 为二维圆盘、无转动、刚度/摩擦为数值参数（非 μ(I) 反算），横向引用、
非专著理论、定性—半定量；三维为简化轴对称刚体滑体极限平衡，非三维 FEM/FELA/SOCP，
三形态命名对齐专著但轴对称推广为程序扩展，与 L1 二维解只作量级对照。
