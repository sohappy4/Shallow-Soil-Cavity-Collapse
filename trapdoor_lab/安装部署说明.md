# 安装与部署说明（银河麒麟 aarch64）

本程序为 Python 3 + 浏览器界面，无需 Qt/VTK。提供两套部署路径：
**源码运行**（推荐，已在本机验证）与 **独立打包版**（无需 Python 环境）。

## 一、环境要求

| 项 | 要求 | 本机已验证 |
|---|---|---|
| 操作系统 | 银河麒麟 V10 SP1（aarch64）或 x86_64 Linux | 银河麒麟 V10 SP1 aarch64 |
| Python | 3.8+ | 3.8.10 |
| 浏览器 | Firefox / Chromium（能访问 127.0.0.1） | Firefox |
| 依赖 | numpy 1.24.4、scipy 1.10.1、matplotlib 3.7.5 | 已装于 `venv` |

说明：PySide6/PyQt5/VTK 在 aarch64 无官方预编译 wheel，故**不采用**；
界面由 Python 标准库 `http.server` 提供，端口 8765 起自动顺延至 8784。

## 二、路径 A：源码运行

### 1. 获取与校验

```bash
cd /home/langchao/桌面/Shallow-Soil-Cavity-Collapse
sha256sum -c MANIFEST.sha256     # 全部 OK 才算完整
```

### 2. 虚拟环境（首次）

```bash
python3 -m venv venv
venv/bin/pip install --no-cache-dir -r requirements.txt
```

若 pip 因 `/tmp` 空间不足报 `Errno 28`，改用项目内临时目录：

```bash
mkdir -p .pip_tmp
TMPDIR="$PWD/.pip_tmp" venv/bin/pip install --no-cache-dir -r requirements.txt
```

### 3. 启动

```bash
cd trapdoor_lab
bash 一键启动.sh
```

终端会打印实际地址（如 `http://127.0.0.1:8765`），浏览器自动打开；
若 8765 被占用会自动换端口，**以终端打印为准**。

### 4. 自检

```bash
../venv/bin/python 自检.py
../venv/bin/python -m unittest discover -s tests
```

## 三、路径 B：独立打包版

### 1. 构建（在有 Python 的机器上）

```bash
cd trapdoor_lab
# 若尚未安装 PyInstaller
mkdir -p ../.pip_tmp
TMPDIR="$(cd .. && pwd)/.pip_tmp" ../venv/bin/python -m pip install --no-cache-dir pyinstaller
bash build.sh
```

`build.sh` 会：
1. 用 PyInstaller `--onedir` 生成 `dist/trapdoor-lab/`；
2. 自动把 `LICENSE`、`THIRD_PARTY_NOTICES.md`、`授权说明.md`、`RELEASE.md`、
   `README.md`、`MANIFEST.sha256` 及五份技术文档、案例模板复制进
   `dist/trapdoor-lab/文档/`。

若 `dist/trapdoor-lab/` 已存在，脚本会提示手动清理（安全策略禁止脚本批量删除）：

```bash
rm -rf dist/trapdoor-lab && bash build.sh
```

### 2. 部署到无 Python 的目标机

把整个 `dist/trapdoor-lab/` 目录拷到目标机（U 盘/内网均可），然后：

```bash
cd dist/trapdoor-lab
bash 启动打包版.sh
```

脚本会探测实际端口并在终端打印浏览器地址；无需目标机安装 Python 或依赖。

注意：打包产物与构建机架构一致（aarch64 构建的只能在 aarch64 运行）。

## 四、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 窗口一闪而过 / 连不上 | 端口被占用 | 看终端打印的实际端口；程序会自动顺延 |
| `No module named numpy` | 用错 Python | 用 `venv/bin/python`，或重新装依赖 |
| pip `Errno 28` | /tmp 是 tmpfs | 设 `TMPDIR` 到项目内 `.pip_tmp` |
| 打包版启动慢 | 首次解压 | 等数秒，看终端端口提示 |
| 浏览器空白 | 代理拦截本地地址 | 浏览器代理设置中对 127.0.0.1 不走代理 |
| 云图中文乱码 | 中文字体缺失 | 安装文泉驿/Noto CJK 字体 |

## 五、卸载与清理

程序不写注册表、不修改系统配置，仅在用户目录生成本地浏览器缓存。
停止服务：在运行终端按 `Ctrl+C`；打包版可 `pkill -f trapdoor-lab`。
直接删除项目目录即完成卸载（删除前请备份自有案例与报告）。
