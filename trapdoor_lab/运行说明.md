## 二、界面怎么用

1. 左侧选「预设土性」或手填参数（σ_c、A、B、σ_t、γ、q₂、l、h）。
2. 选工况：主动塌落 / 被动顶起。
3. 点「开始计算」。右侧立刻给出：判定结论、派生无量纲量、六张图。
4. 点「导出计算报告 (HTML)」可把当前结果和图另存成网页。
5. 左下「试验对照」展开可看论文 Table 3/4 的复现偏差。

**改覆土厚度 h 跨越临界值**（基准算例 h_cr≈5.389 m）时，结论会自动翻转：
- h ≤ h_cr → 「发生整体塌落」
- h > h_cr → 「不会发生整体贯通塌落，仅给出静力/极限解」

## 四、技术说明（为什么不用 PySide6）

实测本机 aarch64 架构下，PySide6 和 PyQt5 在 pip 上均无预编译包
（`No matching distribution found`）。初稿预定的 Qt GUI 路线在本机走不通。
本程序改用 **Python 标准库 http.server + 浏览器**，零额外 GUI 依赖，
只用已有的 numpy / matplotlib。所有计算在内核 `collapse_kernel.py` 完成，
界面只负责显示，两者完全解耦。

## 六、已修正的理论问题（相对 AI 初稿）

1. 埋深比 n = h/(2l) = h/D，不是 h/l（后者翻倍）。
2. q1a/q1b 是输出，不是输入。
3. B=1 走线性极限分支 h_cr = l/A，不再对 `None` 求闭式解。
4. 出露参数统一为 t，不再用未定义的 p。
5. h_cr 门控只对主动工况适用；被动工况按专著不设门控。
6. 术语统一：瓮形（urn）/ 漏斗形（funnel）/ 井筒（shaft）。

## 七、L2 / L3 怎么用

界面左下角的计算/过程按钮：

- **L2 打靶求滑动面**：按专著「算法 17.1」用 RK4 积分 + 二分打靶解滑动面，
  红色实线是打靶解、蓝色虚线是 L1 闭式解，两者应重合。
  结果给出出露点 x₂、水平内缩 L_c、打靶残差、迭代次数，以及三级筛选
  （方向相容 u·s<0 / 耗散 Φ(s)≥0 / 横截条件 σ(x₂)≥−σ_t）的逐项通过情况。
- **L3 速率时间线**：按专著式 (18.1)–(18.7) 计算 Beverloo 出流 Q、
  推进速率 v、贯通时间 T、漏斗终径 R(T)、惯性数 I 与 μ(I)，并给出五阶段。
  先点「显示/隐藏 L3 参数」可改 B_c、d、ρ_b、C_b、φ_r。
- **显示/隐藏 L3 参数**：切换 L3 参数面板。
- 点过「L3 速率时间线」后，结果区下方会出现 **L3 时间线播放**面板：拖动滑块或点
  「播放 / 暂停」，可看到烟囱前锋随 t 推进、当前深度 z 和所处阶段。数据来自同一次
  L3 计算的 120 点时间线，不另起模型。
- **二维坍塌过程动画**（你要的"真正看到土塌下来"）：点后出现动画面板，
  默认 48 帧、可拖动滑块或点「播放 / 暂停」。画面中灰点是静止土、红点是运动土，
  蓝色虚线是 L1/L2 滑面、橙色虚线是 L3 烟囱前锋、底部红线是活门、地表线会随
  漏斗张开而下凹。土粒只在滑体内、且被前锋扫过后才下落，下落量随深度递增、
  受体积守恒缩放；地表漏斗最终张开到 L3 终径 R。**三帧样本见
  `verify/anim_preview.png`。**
  **这是运动学演示，不是 DEM 颗粒流、也不是有限元应力云图**——粒子位移是构造的
  运动学模板，不输出应力/塑性区数值。

- **FEM 二维力学场（应力/塑性区）**：这是真正的数值力学场求解。默认 12×9 网格、
  12 个活门位移步，约需十余秒；面板显示三张图——左为偏应力 q 云图（活门上方
  低应力拱区、两侧应力集中），中为塑性区（红点为屈服单元），右为活门压力—位移
  曲线（初始静止压力骤降后进入残余平台）。面板还给出网格规模、压力降幅、塑性区
  占比、收敛标志与 DP 本构自检结果。**样本见 `verify/fem_preview.png`。**
  该模块是横向引用的成熟有限元方法（按用户 2026-11-24 授权引入），不是专著原有
  理论：DP 圆化准则与专著幂型 Hoek–Brown 不同族，小变形理想弹塑性、网格较粗，
  不作严格 FELA 上下界，只作定性—半定量演示；L1/L2/L3 仍是专著理论主结果。
  Yade/PFC 离散元独立后端（M8）与严格 FELA SOCP 仍未实现。
- **FEM 应力场动态云图**（方案 M5 验收项）：默认 8×6 网格、8 个位移步，约需十余秒。
  面板上方是 GIF 自动播放的演示动图（对应方案 M6「演示视频」的最小实现），
  下方是滑块逐帧查看。可看到偏应力场与塑性区随活门下移逐步演化：step0 无塑性，
  随后活门上方土柱依次屈服，最终形成贯通塑性柱与两侧应力集中。全场统一色标，
  帧间直接可比；每帧显示门压、塑性区占比与迭代残差。**样本见 `verify/fem_demo.gif`。**
  这是 FEM 数值场（非运动学演示），边界同上：DP 圆化、小变形理想弹塑性、非 FELA 上下界。
- **FELA 极限分析上下界夹逼**（方案 M7）：把上下限定理写成一对对偶线性规划。
  线性化屈服面在应力区间取 K 段内接多边形给静力下限抗力 Ra_LB、外接多边形给
  运动上限抗力 Ra_UB；主动支护压力 q=over−Ra/l 是 Ra 的减函数，故夹逼方向反转，
  q∈[q_LB, q_UB]。默认 K=12、41 个滑面离散点，面板显示抗力/支护压力夹逼数值、
  适用域、Davis 折减，以及「上下界夹逼带随 K 收窄 + 区间宽度对数下降」双图。
  实测 L1 闭式解始终落在夹逼区间内，K=2→32 时区间宽从 0.66 收窄到 0.003 kPa。
  **样本见 `verify/fela_bracket.png`。** 边界：线性化多面体极限分析，不是 SOCP
  圆锥规划、不是幂型精确解；下限与 ψ 无关（专著 §7.7.1），Davis 折减单独报告（§7.3）；
  深埋 h/D>1.4 因幂型包线无临界状态封顶，显式标记非物理、不给夹逼结论；
  N_sat=18.2212 仅为文献锚点，本模块不推导。
- **主动/被动镜像对照**：把主动滑面关于洞中线 x=l 镜像，与被动滑面逐点比对，
  给出 x₂a+x₂p=2l 与最大残差（约 1e−5 m，来自 400 点网格插值）。
  若主动出露被裁剪到 x=0（线性分支 dx>l），界面会说明此时不严格镜像。

**一个必须知道的理论边界**：专著演示锚点写 v≈3 m/s、T≈2 s、R≈1.4 m，
对应 h≈6 m、B_c=1 m，即 h/D=6；但同一节又写速率模型严格适用域 h/D≤1.4。
两者是专著自身的张力。程序**不凑数**：如实按公式算（默认给 v≈2.30、T≈2.60、R≈1.86），
并明确标记「超界演示 / rate-degraded」，提示转用静力解。
若要落在严格域内，把 h 调到 ≤1.4×B_c。

## 七·补　GTT 与文献锚点怎么用

左侧「GTT 广义切线法」区有三个按钮：

- **GTT 切点 / 表13.2 / 定理13.2**：按专著式 (13.9)–(13.12) 在切点 σ₀ 作幂型包线切线，
  给出 tanδ_t、δ_t=ψ、c_t 和构造残差；逐项核对表 13.2；再沿 L1 滑动面扫描切点，
  最小化耗散上界。切点框留空时自动取滑面正应力加权均值 σ̄。
  图中黑实线是真实包线、红虚线是切线上界、蓝点划线是弦线下界，右图是定理 13.2 的扫描曲线。
  **表 13.2 第 B=0.5、σ₀=50 kPa 行原书印刷值为 28.56 / 48.96，
  按式 (13.11) 精算是 28.579 / 48.993**；程序把这项原表舍入差明确列出，不放宽容差蒙混。
- **文献锚点 h_sat / h_cr**：核对 N_sat=18.2212 与 h_sat/D=4.555 的自洽关系，
  列出 h_cr/D 与 h_sat/D 的对比表和不同埋深下 L1 外推、L3 适用域判定。
- **二期文献基准集 (1g/离心机)**：展示专著中 19 项有明确数值的文献锚点，分三组：
  1g 试验（McNulty 位移极敏感 0.0002D→50%、h/D≈2 门槛、等沉面高度、位移门槛 3%/10%、
  Abdulla 出露角 61°、Han/Liang 实测 ψ=8.0°/7.5°、Li 覆盖比 2）、
  离心机（Dewoolkar β_eff=4.17–5.26、离散 ±11%、h/D≥5 平台）、
  速率适用域（h/D≲1.4、h/D=2 偏 14%、h/D=10 偏 174%、自稳 ±2%、N_sat=18.2212）。
  每项标注原始文献与专著章节；顶部给出机械自洽核验结果。
  **这些是文献报告值，程序只做自洽核验，不拟合、不推导、不虚构逐点试验曲线。**

**GTT 的理论边界（必须知道）**：专著给出了切线参数和表 13.2，但没有给出机构荷载
Q^UB(σ₀) 的表达式。因此程序只做**固定机构上的耗散积分夹逼**（切线为强度上界、弦线为下界），
不虚构“严格荷载上界”，也不把它冒充完整 FELA 的上下界。定理 13.2 在这里实现的对应形式是：
使耗散上界最小的切点等于滑面正应力弧长加权均值（实测相对误差约 5×10⁻⁸）。

**N_sat 的定位**：它是文献极限分析常数，专著明说无初等闭式、靠上下界夹逼至 1%；
程序只做锚点自洽核验和门槛区分，**不推导、不拟合、不冒充严格上下界**。

## 七·补二　参数扫描动态图件

左侧「参数扫描动态图件」区：选参数（h / A / B / σ_t）、填起点终点和帧数，
点「播放 / 停止扫描」。程序每 0.75 秒重算一次并更新六图与判定；
把 h 的扫描区间设为跨过 h_cr（基准约 5.389 m），可直接看到结论从
「整体贯通塌落」翻转为「不整体贯通」。B 的上限限制为 1.0，超过无定义。
再点一次按钮即停止。

**物理边界（必须知道）**：L1 是闭式解，只给出沿滑面的一维应力场
（σ(z)、τ(z)、ψ(z)），**没有二维应力场**，因此这里实现的是「参数扫描动态图件」，
不是严格意义的二维应力云图。二维云图需要 FELA/有限元层提供场变量，
程序不以线图冒充云图。

- 完整 FELA SOCP 圆锥规划内核：未实现（`cvxpy` 不可用、`scs` 无 aarch64 wheel）。
  当前 FELA 模块用**线性化屈服面的对偶线性规划**实现对偶夹逼（内接下限/外接上限），
  是经典 LP-FELA 路线、非 SOCP、非幂型精确解；且专著未给 Q^UB(σ₀) 表达式，
  所以把夹逼量取为滑面抗力 Ra，不虚构严格机构荷载上界。

- 二维应力云图：L1 只有沿滑面的一维场；真·数值场已由 FEM 模块提供（DP 弹塑性），
  但那不是专著幂型准则的严格解，仅作定性—半定量对照。
